
## Dataset

The AI Resume Screening dataset is included in this repository.

**File:** `ai_resume_screening_dataset.csv`

The dataset contains candidate information, educational qualifications, work experience, technical skills, assessment scores, and recruitment selection outcomes.

**Source:** Kaggle

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

   `pip install pandas numpy matplotlib seaborn jupyter`

3. Open `cleaning.ipynb` in VS Code or Jupyter Notebook.
4. Run the notebook cells in order.

The notebook and dataset should be located in the same project folder.
